# TalkAccess

**Français** — TalkAccess est un logiciel de conversation vocale accessible (client et serveur), pensé d'abord pour les personnes qui utilisent un lecteur d'écran. Ce dépôt ne contient que les versions publiées : les installateurs et les notes de chaque version, dans [Releases](https://github.com/reaperaccessible/TalkAccess/releases). TalkAccess y cherche lui-même ses mises à jour.

**English** — TalkAccess is accessible voice chat software (client and server), designed first for people who use a screen reader. This repository holds only the published versions: the installers and the notes of each version, in [Releases](https://github.com/reaperaccessible/TalkAccess/releases). TalkAccess looks for its own updates here.
